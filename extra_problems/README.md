# 추가 훈련 문제

기본 57문제 밖에서 새 문제를 연습할 때 사용하는 공간입니다. 문제 명세와 테스트를
인터넷에서 한 번 정리해 넣은 뒤에는 오프라인으로 풀고 채점할 수 있습니다.

1. [`templates/new_problem_spec.json`](../templates/new_problem_spec.json)을 복사한다.
2. 설명·제한사항·공개 예제·자체 경계 테스트를 정확히 채운다.
3. `python3 tools/new_problem.py 작성한_명세.json`을 실행한다.
4. 생성된 `solution.py`를 직접 실행하거나 `python3 tools/judge.py 문제번호`로 채점한다.

기본 57문제의 학습 순서와 검증 기준은 바꾸지 않으며, 추가 문제는 유형별 생성 순서로
번호가 붙습니다. 명세 밖 방어 코드가 학습을 왜곡하지 않도록 테스트가 제한사항 안에
있는지는 추가할 때 직접 검토하세요.

> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 문제

문제 정답 배열 `answers`와 다음 세 반복 답안 패턴을 비교한다.
1번은 `1,2,3,4,5`, 2번은 `2,1,2,3,2,4,2,5`, 3번은
`3,3,1,1,2,2,4,4,5,5`를 반복한다. 가장 많이 맞힌 사람 번호를 오름차순
배열로 반환하라.

## 함수 인터페이스

```python
def solution(answers):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 문제 수는 1 이상 10,000 이하이다.
- 각 정답은 1, 2, 3, 4, 5 중 하나이다.
- 최고 점수가 같으면 해당 사람을 모두 포함한다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `answers = [1, 2, 3, 4, 5]` | `[1]` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `answers = [1, 3, 2, 4, 2]` | `[1, 2, 3]` |

## 예제 해설

> **핵심:** 첫 예제의 정답 패턴은 1번 수포자의 반복 답과 모두 일치하고 다른 두 사람보다 많이 맞으므로 `[1]`이다.

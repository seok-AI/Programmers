## 문제

문자 `A,E,I,O,U`만 사용한 길이 1~5의 모든 문자열을 일반적인
사전순으로 나열한다. 첫 항목은 `A`, 마지막 항목은 `UUUUU`이다. 주어진
`word`가 1부터 센 몇 번째 항목인지 반환하라.

## 함수 인터페이스

```python
def solution(word):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `word`의 길이는 1 이상 5 이하이다.
- 각 문자는 대문자 `A`, `E`, `I`, `O`, `U` 중 하나이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `word = 'AAAAE'` | `6` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `word = 'AAAE'` | `10` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `word = 'I'` | `1563` |

### 예제 4

| INPUT | OUTPUT |
|---|---|
| `word = 'EIO'` | `1189` |

## 예제 해설

> **핵심:** 모음 순서 `A,E,I,O,U`로 길이 1~5의 단어를 전위 순회하듯 나열하면 `AAAAE`는 여섯 번째다.

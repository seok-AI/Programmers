> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 문제

`numbers`의 각 문자는 숫자가 적힌 서로 다른 종이 조각 하나다.
일부 또는 전부를 골라 순서를 바꾸어 양의 정수를 만들 수 있다. 이 과정에서
만들 수 있는 서로 다른 소수의 개수를 반환하라. 맨 앞의 0은 수의 값에 영향을
주지 않으며 같은 값은 한 번만 센다.

## 함수 인터페이스

```python
def solution(numbers):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `numbers`의 길이는 1 이상 7 이하이다.
- 문자열에는 `0`부터 `9`까지의 숫자만 등장한다.
- 각 문자 위치는 별도 조각이므로 같은 숫자 문자가 여러 장일 수 있다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `numbers = '17'` | `3` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `numbers = '011'` | `2` |

## 예제 해설

> **핵심:** `17`의 숫자를 한 번 이상 사용해 만들 수 있는 서로 다른 수 중 소수는 7, 17, 71 세 개다.

> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

| 호출 함수 | `solution(number)` |

| 반환형 | `int` |

## 문제

학생별 정수 번호가 `number`에 있다. 서로 다른 인덱스의 학생
세 명을 골라 번호 합이 0이 되는 조합 수를 반환하라. 번호 값이 같아도 학생이
다르면 별개의 조합이 될 수 있다.

## 함수 인터페이스

```python
def solution(number):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `number`의 길이는 3 이상 13 이하이다.
- 각 번호는 -1,000 이상 1,000 이하이다.
- 서로 다른 학생이 같은 번호를 가질 수 있다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `number = [-2, 3, 0, 2, -5]` | `2` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `number = [-3, -2, -1, 0, 1, 2, 3]` | `5` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `number = [-1, 1, -1, 1]` | `0` |

## 예제 해설

> **핵심:** 첫 예제에서 서로 다른 세 인덱스를 고른 합이 0인 조합이 두 개이므로 2를 반환한다.

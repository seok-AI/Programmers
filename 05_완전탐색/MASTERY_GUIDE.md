# 완전탐색 마스터 가이드

## 이 유형의 본질

완전탐색은 “무식하게 다 해본다”가 아니라 **후보 공간을 정확히 정의하고 중복 없이
전부 방문하는 기술**이다. 최적화 문제의 기준 정답을 만들고, 입력 크기가 작을 때
가장 안전한 풀이가 된다. 백트래킹은 완전탐색 중 답이 될 수 없는 가지를 증명으로
잘라내는 방식이다.

마스터는 후보 개수를 먼저 계산하고, 조합·순열·부분집합·격자 위치·수의 구성 중
알맞은 생성 방식을 고른다.

## 문제에서 포착할 신호

- n이 8, 10, 15, 20처럼 매우 작다.
- “가능한 모든 순서/조합/경우” 중 최댓값·최솟값을 요구한다.
- 자릿수나 단어 길이가 7 이하이다.
- 회전, 배치, 절단 위치 등 선택지가 유한하고 작다.
- 뚜렷한 그리디 기준이 없고 선택 순서가 미래 가능성에 영향을 준다.
- 정답 후보를 직접 생성해 검사하기 쉽다.

## 후보 공간 계산

코드보다 먼저 상한을 적는다.

- n개 중 r개 선택: `C(n, r)`
- n개 순서 배치: `n!`
- 각 원소 선택/미선택: `2^n`
- 길이 d, 문자 종류 k: `k^d`
- n×m 모든 시작점과 네 방향: `O(nm)` 또는 그 배수

예를 들어 던전 8개의 모든 순서는 `8! = 40,320`이라 충분히 가능하다. 숫자 조각
7개의 모든 길이 순열도 대략 수만 수준이다. 계산 없이 “느릴 것 같다”고 더 복잡한
알고리즘을 고르지 않는다.

## 사고 절차

1. 후보 하나가 무엇인지 정의한다.
2. 후보를 표현하는 최소 상태를 정한다.
3. 후보 총수를 계산한다.
4. 중복 후보가 생기는지 확인한다.
5. 후보 하나의 검증 비용을 곱해 전체 복잡도를 구한다.
6. 가지치기 조건이 정답 후보를 제거하지 않음을 증명한다.

## 구현 패턴

### 조합과 순열

```python
from itertools import combinations, permutations

for chosen in combinations(items, r):
    evaluate(chosen)

for order in permutations(items):
    simulate(order)
```

### 직접 백트래킹

```python
def search(depth, state):
    if depth == target_depth:
        update_answer(state)
        return

    for choice in choices(state):
        if not feasible(state, choice):
            continue
        apply(state, choice)
        search(depth + 1, state)
        undo(state, choice)
```

`apply`와 `undo`는 정확히 대칭이어야 한다. 복구 누락을 피하려면 작은 상태는 복사해
넘기는 방식과 성능을 비교한다.

### 부분집합 비트마스크

```python
for mask in range(1 << n):
    chosen = [items[i] for i in range(n) if mask & (1 << i)]
```

## 가지치기 원칙

좋은 가지치기는 “현재 상태에서 어떤 선택을 더 해도 기존 최적값을 이길 수 없다”처럼
미래 상한/하한을 사용한다. 단순히 경험상 가능성이 낮다는 이유로 자르면 안 된다.

- 제약 위반: 이후 선택으로 복구 불가능하면 즉시 중단
- 중복 제거: 같은 깊이에서 같은 값 선택을 한 번만 허용
- 최적 상한: 남은 것을 모두 얻어도 답을 갱신할 수 없으면 중단
- 순서 대칭: 서로 바꿔도 같은 상태인 후보를 정규화

## 자주 틀리는 이유

- 값이 같은 서로 다른 인덱스를 같은 후보로 합친다.
- 사용 표시를 재귀 복귀 후 복구하지 않는다.
- 길이 1부터 n까지가 필요한데 n 길이만 생성한다.
- 숫자 `0`이 앞에 오는 순열과 정수 변환의 중복을 놓친다.
- 소수 판정에서 0과 1을 소수로 처리한다.
- 가지치기의 정당성을 증명하지 않고 정답 경로를 잘라낸다.

## 검증과 훈련법

- 작은 랜덤 입력에서 최적화 풀이를 완전탐색 기준 풀이와 수천 번 비교한다.
- 조합/순열/부분집합의 후보 수를 실제 카운트해 수식과 맞는지 확인한다.
- 라이브러리 버전과 직접 재귀 버전을 모두 작성한다.
- 재귀 함수의 인자마다 “미래 결정에 정말 필요한가?”를 묻고 상태를 최소화한다.

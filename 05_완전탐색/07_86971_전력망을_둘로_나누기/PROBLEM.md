## 문제

1번부터 n번까지의 송전탑이 n-1개 전선으로 연결된 하나의
트리이다. `wires` 중 정확히 한 전선을 끊어 두 연결 요소로 나눌 때, 두 요소의
정점 수 차이의 절댓값을 최소화하여 그 값을 반환하라.

## 함수 인터페이스

```python
def solution(n, wires):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `n`은 2 이상 100 이하이다.
- `wires`의 길이는 `n-1`이다.
- 각 전선은 `[v1, v2]`이고 `1 <= v1 < v2 <= n`이다.
- 입력 그래프는 항상 하나의 트리이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `n = 9; wires = [[1, 3], [2, 3], [3, 4], [4, 5], [4, 6], [4, 7], [7, 8], [7, 9]]` | `3` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `n = 4; wires = [[1, 2], [2, 3], [3, 4]]` | `0` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `n = 7; wires = [[1, 2], [2, 7], [3, 7], [3, 4], [4, 5], [6, 7]]` | `1` |

## 예제 해설

> **핵심:** 간선을 하나씩 제거해 양쪽 송전탑 수를 세면 가장 균형 잡힌 분할의 차이가 3이다.

# 풀이 출처와 재작성 범위

이 폴더의 코드는 특정 온라인 정답 파일을 복사한 것이 아닙니다. 널리 알려진
알고리즘 발상을 참고하여 Python 함수로 독립 작성했습니다. 따라서 아래 링크는
아이디어 비교·추적용이며, 현재 코드의 원문 출처라고 주장하지 않습니다.

- 공개 풀이 데이터 스냅숏: <https://github.com/codeisneverodd/programmers-coding-test/blob/a7e263009f5cc5694957b10b91005dc2dbc2129d/data/solutions.json>

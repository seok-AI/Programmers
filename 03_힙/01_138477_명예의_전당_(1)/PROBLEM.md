## 문제

매일 한 점수가 `score` 순서로 들어온다. 그날까지의 점수 중 큰
순서로 최대 k개만 명예 목록에 유지한다. 매일 갱신이 끝난 뒤 목록에서 가장
낮은 점수를 발표한다. 날짜별 발표 점수를 배열로 반환하라. 아직 k일이 지나지
않았다면 지금까지 들어온 점수는 모두 목록에 있다.

## 함수 인터페이스

```python
def solution(k, score):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `k`는 3 이상 100 이하이다.
- `score`의 길이는 7 이상 1,000 이하이다.
- 각 점수는 0 이상 2,000 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `k = 3; score = [10, 100, 20, 150, 1, 100, 200]` | `[10, 10, 10, 20, 20, 100, 100]` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `k = 4; score = [0, 300, 40, 300, 20, 70, 150, 50, 500, 1000]` | `[0, 0, 0, 0, 20, 40, 70, 70, 150, 300]` |

## 예제 해설

> **핵심:** 첫 3일까지는 지금까지의 최저 점수를 발표하고, 이후에는 상위 3개만 남긴 뒤 그중 최저 점수를 발표한다.

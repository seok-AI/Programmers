## 문제

음식별 매운 정도 `scoville`의 모든 값을 K 이상으로 만들려 한다.
매번 가장 작은
두 값 a, b를 꺼내 `a + 2*b`인 새 음식 하나로 합친다. 목표를 달성하는 최소
혼합 횟수를 반환하고, 끝내 달성할 수 없으면 -1을 반환하라.

## 함수 인터페이스

```python
def solution(scoville, K):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `scoville`의 길이는 2 이상 1,000,000 이하이다.
- `K`는 0 이상 1,000,000,000 이하이다.
- 초기 매운 정도는 0 이상 1,000,000 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `scoville = [1, 2, 3, 9, 10, 12]; K = 7` | `2` |

## 예제 해설

> **핵심:** 첫 예제에서 가장 작은 1과 2를 섞어 5를 만들고, 다시 3과 5를 섞어 13을 만들면 모든 값이 7 이상이 되어 두 번이다.

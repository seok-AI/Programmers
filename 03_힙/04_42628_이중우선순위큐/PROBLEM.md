# 이중우선순위큐 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |

| 학습 유형 | 힙(Heap) |
| 호출 함수 | `solution(operations)` |

| 반환형 | `list` |

## 문제

빈 이중 우선순위 큐에 `operations`를 순서대로 적용한다. `I x`는
x 삽입, `D 1`은 최댓값 하나 삭제, `D -1`은 최솟값 하나 삭제이다. 빈 큐의
삭제 명령은 무시한다. 마지막에 비었으면 `[0, 0]`, 아니면
`[최댓값, 최솟값]`을 반환하라.

## 함수 인터페이스

```python
def solution(operations):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 명령 수는 1 이상 1,000,000 이하이다.
- 삭제할 극값이 여러 번 들어 있어도 한 원소만 삭제한다.
- 각 원소는 공백으로 명령과 정수가 구분된 문자열이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `operations = ['I 16', 'I -5643', 'D -1', 'D 1', 'D 1', 'I 123', 'D -1']` | `[0, 0]` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `operations = ['I -45', 'I 653', 'D 1', 'I -642', 'I 45', 'I 97', 'D 1', 'D -1', 'I 333']` | `[333, -45]` |

## 예제 해설

> **핵심:** 첫 예제는 삽입과 양끝 삭제를 모두 적용한 뒤 큐가 비므로 `[0, 0]`을 반환한다. 빈 큐에 대한 추가 삭제는 무시한다.

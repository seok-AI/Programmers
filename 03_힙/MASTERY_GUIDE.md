# 힙 마스터 가이드

## 이 유형의 본질

힙은 데이터 전체를 정렬하려는 도구가 아니라, 데이터가 계속 변하는 동안 **현재의
최솟값 또는 최댓값을 반복해서 꺼내는 도구**다. 삽입과 극값 삭제가 각각
`O(log n)`, 극값 조회가 `O(1)`이라는 점이 핵심이다.

마스터는 “한 번 정렬 후 순회”와 “동적으로 힙 유지” 중 무엇이 필요한지 구분하고,
힙 안에 들어갈 수 있는 후보의 조건을 정확히 정의한다.

## 문제에서 포착할 신호

- 매 단계 가장 작거나 큰 항목을 선택하고 제거한다.
- 작업/점수가 시간 순으로 계속 추가된다.
- 상위 k개 또는 하위 k개만 유지하면 된다.
- 전체 정렬을 매 갱신마다 반복하면 너무 느리다.
- 우선순위가 여러 기준으로 결정된다.
- 두 개의 극값을 모두 삭제해야 한다.

극값을 한 번만 구하면 `min`/`max`, 입력이 모두 정해져 있고 한 번 순회하면 정렬,
삽입과 극값 처리가 반복되면 힙을 우선 검토한다.

## 사고 절차

1. 언제 새 후보가 활성화되는지 정한다.
2. 활성 후보 중 무엇이 다음 선택의 우선순위인지 튜플로 쓴다.
3. 힙에 들어간 원소가 의미하는 상태를 정의한다.
4. 선택 후 새로 활성화되는 후보와 삭제되는 후보를 분리한다.
5. 원소 하나가 몇 번 push/pop되는지 세어 복잡도를 계산한다.

스케줄링의 핵심 불변식 예시는 “현재 시각 이전에 요청된 미처리 작업만 힙에 있다”이다.
이 불변식이 맞으면 힙의 루트가 지금 선택 가능한 최우선 작업이다.

## 구현 패턴

### 최소 힙과 최대 힙

```python
import heapq

min_heap = []
heapq.heappush(min_heap, value)
smallest = heapq.heappop(min_heap)

max_heap = []
heapq.heappush(max_heap, -value)
largest = -heapq.heappop(max_heap)
```

### 여러 우선순위

```python
# 실행 시간, 요청 시각, 작업 번호 순으로 작은 항목 우선
heapq.heappush(heap, (duration, requested_at, job_id))
```

Python 튜플은 앞 필드부터 비교한다. 서로 비교할 수 없는 객체를 동률 위치에 넣지 않는다.

### 상위 k개 유지

```python
heap = []
for value in stream:
    heapq.heappush(heap, value)
    if len(heap) > k:
        heapq.heappop(heap)
    current_kth = heap[0]
```

### 지연 삭제

두 힙으로 최소·최대를 모두 관리할 때 삭제된 항목을 별도 빈도표에 기록하고, 힙 루트가
이미 삭제된 값이면 실제 pop하는 지연 삭제를 사용한다. 두 힙의 크기가 같다고 가정하지
말고 유효 원소 수를 별도로 추적한다.

## 이 폴더의 추천 학습 순서

1. `01_138477_명예의_전당_(1)`: 크기 k의 최소 힙을 유지한다.
2. `02_42626_더_맵게`: 매번 가장 작은 두 원소를 꺼내고 다시 삽입한다.
3. `03_42627_디스크_컨트롤러`: 시간 정렬과 활성 후보 힙을 결합한다.
4. `04_42628_이중우선순위큐`: 두 극값, 중복, 동기화 문제를 다룬다.

각 문제에서 정렬만으로 풀 수 있는지 먼저 검토하고, 힙이 필요한 이유를 한 줄로 남긴다.

## 자주 틀리는 이유

- 최대 힙 음수 변환 후 부호를 되돌리지 않는다.
- 우선순위 튜플 필드 순서를 문제의 동률 규칙과 다르게 둔다.
- 아직 요청되지 않은 작업까지 힙에 넣는다.
- 대기 힙이 비었을 때 시각을 1씩 증가시켜 큰 공백에서 시간 초과가 난다.
- 두 힙에서 한쪽만 삭제해 유령 원소가 남는다.
- 중복 값 하나 삭제와 같은 값 전체 삭제를 혼동한다.

## 복잡도 판단

n개 원소가 각각 한 번 삽입되고 한 번 삭제되면 `O(n log n)`이다. 힙을 매 반복마다
새로 만들거나 내부 배열을 선형 검색해 삭제하면 이 보장이 깨진다. `heapify`는 n개를
한꺼번에 힙으로 만들 때 `O(n)`이다.

## 효율적인 훈련법

- 정렬 풀이와 힙 풀이를 모두 작성하고 입력이 스트림일 때의 차이를 설명한다.
- 스케줄링 문제는 요청 시각, 처리 시간, 우선순위를 무작위 생성해 작은 기준 풀이와 비교한다.
- 상위 k, 중앙값 스트림, k개 리스트 병합으로 확장한다.
- 이중 힙에서는 중복 값 10개, 빈 큐 삭제, 최소=최대인 사례를 집중 테스트한다.

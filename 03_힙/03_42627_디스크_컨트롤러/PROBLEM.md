## 문제

`jobs[i] = [요청 시각, 실행 시간]`인 비선점 디스크 작업을
스케줄링한다. 디스크가 비고 대기 작업이 있으면 실행 시간이 짧은 작업을 먼저
고르며, 동률이면 요청 시각, 다시 동률이면 원래 작업 번호가 작은 순서다.
작업의 반환 시간은 `종료 시각 - 요청 시각`이다. 모든 반환 시간 평균의
소수점 아래를 버린 정수를 반환하라.

## 함수 인터페이스

```python
def solution(jobs):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 작업 수는 1 이상 500 이하이다.
- 요청 시각은 0 이상 1,000 이하이다.
- 실행 시간은 1 이상 1,000 이하이다.
- 한 번 시작한 작업은 완료할 때까지 중단하지 않는다.
- 완료와 새 요청이 같은 시각이면 새 요청도 대기 큐에 넣은 뒤 다음 작업을 고른다.
- 대기 작업이 없으면 다음 요청 시각까지 디스크는 쉰다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `jobs = [[0, 3], [1, 9], [3, 5]]` | `8` |

## 예제 해설

> **핵심:** 요청된 작업 중 실행 시간이 짧은 작업을 선택하고 유휴 시간에는 다음 요청으로 이동한다. 각 종료 시각에서 요청 시각을 뺀 값의 평균을 버리면 8이다.

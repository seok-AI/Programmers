## 문제

0번부터 n-1번까지의 섬과 건설 가능한 다리
`[섬1, 섬2, 비용]` 목록 `costs`가 주어진다. 여러 다리를 거쳐서라도 모든
섬 쌍이 오갈 수 있게 만드는 총 건설 비용의 최솟값을 반환하라.

## 함수 인터페이스

```python
def solution(n, costs):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `n`은 1 이상 100 이하이다.
- `costs`의 길이는 최대 `n*(n-1)/2`이다.
- 같은 무방향 섬 쌍의 비용은 한 번만 주어진다.
- 목록에 없는 다리는 건설할 수 없다.
- 모든 섬을 연결할 수 있는 입력만 주어진다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `n = 4; costs = [[0, 1, 1], [0, 2, 2], [1, 2, 5], [1, 3, 1], [2, 3, 8]]` | `4` |

## 예제 해설

> **핵심:** 비용이 낮은 간선부터 서로 다른 연결요소를 잇는 간선만 선택하면 모든 섬을 잇는 최소 비용이 4이다.

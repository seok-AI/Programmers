# 큰 수 만들기 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 난이도 | Level 2 |
| 학습 유형 | 탐욕법(Greedy) |
| 호출 함수 | `solution(number, k)` |
| 매개변수 | `number`, `k` |
| 반환형 | `str` |

## 문제

숫자 문자열 `number`에서 정확히 k개의 문자를 삭제한다.
남은 문자들의 상대적 순서는 바꿀 수 없다. 만들 수 있는 가장 큰 숫자 문자열을
반환하라.

## 함수 인터페이스

```python
def solution(number, k):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `number`의 길이는 2 이상 1,000,000 이하이다.
- `number`에는 숫자 문자만 들어 있다.
- `k`는 1 이상 `len(number)-1` 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `number = '1924'; k = 2` | `'94'` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `number = '1231234'; k = 3` | `'3234'` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `number = '4177252841'; k = 4` | `'775841'` |

## 예제 해설

> **핵심:** 앞자리부터 더 큰 숫자를 남기도록 작은 앞자리 숫자 두 개를 제거하면 `1924`에서 가장 큰 결과는 `94`이다.

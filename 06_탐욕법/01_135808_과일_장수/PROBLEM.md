# 과일 장수 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

| 항목 | 내용 |

| 학습 유형 | 탐욕법(Greedy) |
| 호출 함수 | `solution(k, m, score)` |
| 매개변수 | `k`, `m`, `score` |
| 반환형 | `int` |

## 문제

사과 점수는 1부터 k까지이고 `score`에 모든 사과가 기록된다.
한 상자는 정확히 m개이며, 상자 가격은 `m * 상자 안 최저 점수`이다. 상자
단위로만 팔고 남는 사과는 버릴 때 얻을 수 있는 총수익의 최댓값을 반환하라.

## 함수 인터페이스

```python
def solution(k, m, score):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `k`는 3 이상 9 이하이다.
- `m`은 3 이상 10 이하이다.
- `score`의 길이는 7 이상 1,000,000 이하이다.
- 각 점수는 1 이상 k 이하이다.
- 상자를 하나도 만들 수 없으면 0을 반환한다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `k = 3; m = 4; score = [1, 2, 3, 1, 2, 3, 1]` | `8` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `k = 4; m = 3; score = [4, 1, 2, 2, 4, 4, 4, 4, 1, 2, 4, 2]` | `33` |

## 예제 해설

> **핵심:** 높은 점수부터 상자 크기 4개씩 묶고 각 상자의 최저 점수에 4를 곱한다. 완성되지 않은 사과는 버려 총점 8이다.

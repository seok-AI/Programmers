# 단계별 힌트

한 번에 전부 열지 말고, 막힌 뒤 현재 단계 하나만 확인하세요.

<details>
<summary>1단계 — 복잡도 목표</summary>

- 유형: `02_스택_큐`
- 목표: `O(n) time, O(n) space` 안에서 동작하는 구조를 찾으세요.

</details>

<details>
<summary>2단계 — 핵심 접근</summary>

`기능별 완료일 계산 후 비감소 배포 경계 그룹화` 방식을 검토하세요. 입력을 읽는 순간 무엇을 저장하고, 언제 답이
확정되는지 두 문장으로 먼저 적어 보세요.

</details>

<details>
<summary>3단계 — 상태·불변식</summary>

코드를 쓰기 전에 아래 두 문장을 자신의 말로 설명할 수 있는지 확인하세요.

- 상태 정의: 각 기능의 완료일과 현재 배포 묶음의 기준 완료일을 유지한다.
- 핵심 불변식: 현재 묶음에는 선두 기능의 완료일까지 끝나는 연속 기능만 들어간다.

</details>

<details>
<summary>4단계 — 구현 순서 의사코드</summary>

정답 코드는 노출하지 않습니다. 아래 순서만 보고 자신의 변수와 제어문으로 옮기세요.

1. 각 기능이 100에 도달하는 일수를 올림 계산한다.
2. 첫 완료일을 현재 배포일로 잡는다.
3. 그 이하인 연속 기능은 같은 묶음에 센다.
4. 더 늦은 기능에서 이전 묶음을 닫고 새 묶음을 시작한다.

</details>

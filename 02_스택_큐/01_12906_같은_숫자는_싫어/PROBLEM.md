## 문제

숫자 배열 `arr`에서 같은 값이 연속된 각 구간을 그 값 하나로
압축하라. 서로 떨어져 나타난 같은 숫자는 제거하지 않으며 원래 순서를 유지한
배열을 반환한다.

## 함수 인터페이스

```python
def solution(arr):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `arr`의 길이는 1 이상 1,000,000 이하이다.
- 각 원소는 0 이상 9 이하의 정수이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `arr = [1, 1, 3, 3, 0, 1, 1]` | `[1, 3, 0, 1]` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `arr = [4, 4, 4, 3, 3]` | `[4, 3]` |

## 예제 해설

> **핵심:** 첫 예제의 연속 구간은 `1`, `3`, `0`, `1` 네 덩어리다. 각 덩어리의 첫 값만 남긴 결과를 반환한다.

## 문제

초마다 측정한 가격 `prices`가 주어진다. 각 시점 i에 대해 그
시점부터 가격이 처음으로 더 낮아지는 시점까지의 초 수를 구한다. 끝까지
떨어지지 않으면 배열의 마지막 시점까지 경과한 시간을 기록하여 반환하라.

## 함수 인터페이스

```python
def solution(prices):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `prices`의 길이는 2 이상 100,000 이하이다.
- 각 가격은 1 이상 10,000 이하의 정수이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `prices = [1, 2, 3, 2, 3]` | `[4, 3, 1, 1, 0]` |

## 예제 해설

> **핵심:** 첫 가격 1은 끝까지 하락하지 않아 4초, 가격 3은 바로 다음 시점의 2에서 하락해 1초가 된다. 같은 방식으로 각 시점의 지속 시간을 계산한다.

> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 문제

재료가 `ingredient` 순서로 스택 위에 놓인다. 번호 1은 빵,
2는 채소, 3은 고기이다. 스택의 연속된 맨 위 네 재료가 아래부터
`[1, 2, 3, 1]`이 되는 즉시 이를 제거해 햄버거 하나를 포장한다. 모든 재료를
처리한 뒤 만든 햄버거 수를 반환하라.

## 함수 인터페이스

```python
def solution(ingredient):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `ingredient`의 길이는 1 이상 1,000,000 이하이다.
- 각 원소는 1, 2, 3 중 하나이다.
- 포장 중 새 재료가 들어오지 않으므로 완성 패턴은 즉시 제거된다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `ingredient = [2, 1, 1, 2, 3, 1, 2, 3, 1]` | `2` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `ingredient = [1, 3, 2, 1, 2, 1, 3, 1, 2]` | `0` |

## 예제 해설

> **핵심:** 재료를 차례로 쌓을 때 맨 위가 `[1,2,3,1]`이 되는 순간 두 번 제거되므로 햄버거 수는 2이다.

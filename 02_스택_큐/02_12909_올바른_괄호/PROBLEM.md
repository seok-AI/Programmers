# 올바른 괄호 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |

| 난이도 | Level 2 |
| 학습 유형 | 스택/큐 |
| 호출 함수 | `solution(s)` |
| 매개변수 | `s` |
| 반환형 | `bool` |

## 문제

`s`는 여는 괄호와 닫는 괄호만으로 이루어진다. 왼쪽부터 읽을 때
어떤 접두 구간에서도 닫는 괄호가 여는 괄호보다 많지 않고, 전체의 두 괄호
수가 같으면 올바른 문자열이다. 올바르면 `True`, 아니면 `False`를 반환하라.

## 함수 인터페이스

```python
def solution(s):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `s`의 길이는 1 이상 100,000 이하이다.
- 등장 문자는 `(`와 `)`뿐이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `s = '()()'` | `True` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `s = '(())()'` | `True` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `s = ')()('` | `False` |

### 예제 4

| INPUT | OUTPUT |
|---|---|
| `s = '(()('` | `False` |

## 예제 해설

> **핵심:** 첫 예제는 왼쪽부터 확인하는 동안 닫는 괄호 수가 여는 괄호 수를 앞서지 않고 마지막 균형도 0이므로 올바르다.

## 문제

대기 큐의 프로세스 우선순위가 `priorities`로 주어진다. 맨 앞
프로세스를 꺼냈을 때 큐 안에 더 높은 우선순위가 하나라도 있으면 맨 뒤로
보내고, 없으면 실행 후 제거한다. 최초 위치가 `location`인 프로세스가 몇
번째로 실행되는지 1부터 세어 반환하라.

## 함수 인터페이스

```python
def solution(priorities, location):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `priorities`의 길이는 1 이상 100 이하이다.
- 우선순위는 1 이상 9 이하이며 큰 값이 더 높다.
- `location`은 0 이상 `len(priorities)-1` 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `priorities = [2, 1, 3, 2]; location = 2` | `1` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `priorities = [1, 1, 9, 1, 1, 1]; location = 0` | `5` |

## 예제 해설

> **핵심:** 첫 예제에서는 우선순위 3인 목표 프로세스보다 높은 작업이 없으므로 가장 먼저 실행되어 1을 반환한다.

# 실전 참조 스니펫

문제 풀이를 복사해 두는 폴더가 아니라, 시험 전에 손으로 재현해야 할 최소 골격과
불변식을 확인하는 곳입니다. 각 파일은 표준 라이브러리만 사용하며 직접 실행하면
작은 자체 검증을 수행합니다.

| 파일 | 언제 쓰는가 | 외울 불변식 |
|---|---|---|
| [`bfs.py`](./bfs.py) | 무가중 그래프 최단거리, 격자 탐색 | 큐에 처음 넣을 때 최단거리 확정 |
| [`union_find.py`](./union_find.py) | 연결요소 병합, Kruskal MST | 대표가 같으면 이미 같은 집합 |
| [`dijkstra.py`](./dijkstra.py) | 음수 없는 가중 그래프 최단거리 | 힙에서 꺼낸 거리가 현재 기록보다 크면 폐기 |

```bash
python3 snippets/bfs.py
python3 snippets/union_find.py
python3 snippets/dijkstra.py
```

스니펫을 보지 않고 10분 안에 다시 쓴 뒤, 정점 번호 범위·방향성·도달 불가능 값과
입력 최대 크기에 맞게 자료구조를 바꾸는 연습을 하세요.

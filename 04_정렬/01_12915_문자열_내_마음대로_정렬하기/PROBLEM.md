## 문제

`strings`를 각 문자열의 0부터 센 n번 인덱스 문자 기준으로
오름차순 정렬한다. 그 문자가 같으면 문자열 전체의 사전순으로 정렬하여
결과 배열을 반환하라.

## 함수 인터페이스

```python
def solution(strings, n):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `strings`의 길이는 1 이상 50 이하이다.
- 각 원소는 길이 1~100의 알파벳 소문자 문자열이다.
- 모든 문자열 길이는 `n`보다 크다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `strings = ['sun', 'bed', 'car']; n = 1` | `['car', 'bed', 'sun']` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `strings = ['abce', 'abcd', 'cdx']; n = 2` | `['abcd', 'abce', 'cdx']` |

## 예제 해설

> **핵심:** 첫 예제는 각 문자열의 두 번째 문자를 기준으로 정렬한다. 해당 문자가 `a`, `e`, `u` 순서여서 `car`, `bed`, `sun`이 된다.

# 가장 큰 수 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 난이도 | Level 2 |
| 학습 유형 | 정렬 |
| 호출 함수 | `solution(numbers)` |
| 매개변수 | `numbers` |
| 반환형 | `str` |

## 문제

0 이상의 정수 배열 `numbers`의 모든 원소를 한 번씩 사용하여
문자열로 이어 붙인다. 원소 순서를 바꾸어 만들 수 있는 수 중 가장 큰 값을
문자열로 반환하라.

## 함수 인터페이스

```python
def solution(numbers):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `numbers`의 길이는 1 이상 100,000 이하이다.
- 각 원소는 0 이상 1,000 이하이다.
- 결과가 매우 클 수 있으므로 정수가 아닌 문자열로 반환한다.
- 모든 원소가 0이라면 결과는 여러 0이 아닌 `"0"`이어야 한다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `numbers = [6, 10, 2]` | `'6210'` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `numbers = [3, 30, 34, 5, 9]` | `'9534330'` |

## 예제 해설

> **핵심:** 첫 예제에서는 이어 붙였을 때 `6`, `2`, `10` 순서가 가장 큰 문자열을 만들므로 `6210`이다.

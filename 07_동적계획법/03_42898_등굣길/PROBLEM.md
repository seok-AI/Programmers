## 문제

가로 m, 세로 n 격자에서 집 `(1,1)`부터 학교 `(m,n)`까지
오른쪽 또는 아래로만 이동한다. `puddles`의 좌표는 밟을 수 없다. 가능한
최단 경로 수를 1,000,000,007로 나눈 나머지를 반환하라.

## 함수 인터페이스

```python
def solution(m, n, puddles):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `m`과 `n`은 각각 1 이상 100 이하이다.
- `m == n == 1`인 입력은 없다.
- 물웅덩이는 0개 이상 10개 이하이며 `[x, y]` 좌표로 주어진다.
- 집과 학교는 물웅덩이가 아니다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `m = 4; n = 3; puddles = [[2, 2]]` | `4` |

## 예제 해설

> **핵심:** 오른쪽·아래쪽으로 오는 경로 수를 더하되 웅덩이 칸을 0으로 두면 학교까지 가능한 경로가 4개다.

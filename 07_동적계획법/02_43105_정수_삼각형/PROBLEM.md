## 문제

`triangle[r]`에는 r+1개의 수가 있다. 꼭대기에서 시작해 다음
행으로 내려갈 때 현재 열 또는 현재 열+1의 칸만 선택할 수 있다. 바닥까지
선택한 값 합의 최댓값을 반환하라.

## 함수 인터페이스

```python
def solution(triangle):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 삼각형 높이는 1 이상 500 이하이다.
- 각 값은 0 이상 9,999 이하이다.
- r번째 행의 길이는 r+1이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `triangle = [[7], [3, 8], [8, 1, 0], [2, 7, 4, 4], [4, 5, 2, 6, 5]]` | `30` |

## 예제 해설

> **핵심:** 각 칸까지 올 수 있는 경로의 최대 합만 남기며 아래로 내려가면 마지막 행의 최댓값이 30이다.

# N으로 표현 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |

| 매개변수 | `N`, `number` |
| 반환형 | `int` |

## 문제

숫자 N을 1회 이상 이어 붙인 수(예: N=5일 때 5, 55, 555)와
사칙연산, 괄호를 사용해 `number`를 표현한다. 사용한 N의 총개수가 가장 적은
식의 개수를 반환하고, 8개 이내로 표현할 수 없으면 -1을 반환하라.

## 함수 인터페이스

```python
def solution(N, number):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `N`은 1 이상 9 이하이다.
- `number`는 1 이상 32,000 이하이다.
- 허용 연산은 `+`, `-`, `*`, `/`와 괄호이다.
- 정수 나눗셈 결과는 0 방향으로 소수 부분을 버린다.
- 최소 사용량이 8보다 크면 -1이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `N = 5; number = 12` | `4` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `N = 2; number = 11` | `3` |

## 예제 해설

> **핵심:** 숫자 5를 네 번 사용한 `55/5+5`가 12를 만든다. 세 번 이하로는 만들 수 없어 답은 4이다.

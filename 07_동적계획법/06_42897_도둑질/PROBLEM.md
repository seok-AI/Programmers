> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

| 항목 | 내용 |

| 학습 유형 | 동적계획법(Dynamic Programming) |
| 호출 함수 | `solution(money)` |
| 매개변수 | `money` |
| 반환형 | `int` |

## 문제

원형으로 배치된 집마다 훔칠 돈이 `money`에 있다. 서로 이웃한
두 집을 모두 털면 안 되며, 첫 집과 마지막 집도 이웃이다. 선택한 집에서 훔칠
수 있는 총액의 최댓값을 반환하라.

## 함수 인터페이스

```python
def solution(money):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 집 수는 3 이상 1,000,000 이하이다.
- 각 금액은 0 이상 1,000 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `money = [1, 2, 3, 1]` | `4` |

## 예제 해설

> **핵심:** 집이 원형이므로 첫 집을 고르는 경우와 마지막 집을 고르는 경우를 분리한다. 두 선형 DP의 큰 값이 4다.

# 타겟 넘버 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 난이도 | Level 2 |
| 학습 유형 | 깊이/너비 우선 탐색(DFS/BFS) |
| 호출 함수 | `solution(numbers, target)` |
| 매개변수 | `numbers`, `target` |
| 반환형 | `int` |

## 문제

`numbers`의 순서를 유지하면서 각 수 앞에 `+` 또는 `-`를
정확히 하나씩 붙인다. 계산 결과가 `target`이 되는 부호 선택 방법의 수를
반환하라.

## 함수 인터페이스

```python
def solution(numbers, target):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `numbers`의 길이는 2 이상 20 이하이다.
- 각 수는 1 이상 50 이하이다.
- `target`은 1 이상 1,000 이하이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `numbers = [1, 1, 1, 1, 1]; target = 3` | `5` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `numbers = [4, 1, 2, 1]; target = 4` | `2` |

## 예제 해설

> **핵심:** 다섯 개의 1에 각각 + 또는 -를 붙인 모든 경우 중 합이 3인 부호 배치가 다섯 개다.

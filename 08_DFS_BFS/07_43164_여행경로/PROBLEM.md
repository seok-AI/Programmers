## 문제

`tickets[i] = [출발, 도착]`인 항공권을 각각 정확히 한 번
사용하며 `ICN`에서 출발한다. 가능한 전체 공항 방문 순서 가운데 문자열 배열의
사전순이 가장 앞서는 경로를 반환하라.

## 함수 인터페이스

```python
def solution(tickets):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 공항 코드는 알파벳 대문자 세 글자이다.
- 항공권은 3개 이상 10,000개 이하이다.
- 같은 구간의 항공권이 여러 장일 수 있으며 각 장을 따로 사용해야 한다.
- 모든 항공권을 사용하는 경로가 적어도 하나 존재한다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `tickets = [['ICN', 'JFK'], ['HND', 'IAD'], ['JFK', 'HND']]` | `['ICN', 'JFK', 'HND', 'IAD']` |

### 예제 2

**INPUT**

```python
tickets = [['ICN', 'SFO'],
           ['ICN', 'ATL'],
           ['SFO', 'ATL'],
           ['ATL', 'ICN'],
           ['ATL', 'SFO']]
```

**OUTPUT**

```python
['ICN', 'ATL', 'ICN', 'SFO', 'ATL', 'SFO']
```

## 예제 해설

> **핵심:** 모든 항공권을 한 번씩 사용하면서 `ICN`에서 시작하면 첫 예제의 연결 순서는 `ICN→JFK→HND→IAD`로 유일하다.

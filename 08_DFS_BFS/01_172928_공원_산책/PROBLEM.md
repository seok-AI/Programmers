# 공원 산책 — 오프라인 문제 명세

> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 난이도 | Level 1 |
| 학습 유형 | 깊이/너비 우선 탐색(DFS/BFS) |
| 호출 함수 | `solution(park, routes)` |
| 매개변수 | `park`, `routes` |
| 반환형 | `list` |

## 문제

`park`는 시작 `S`, 통로 `O`, 장애물 `X`로 된 직사각형이다.
각 `routes`는 `"방향 거리"` 형식이다. 한 명령의 이동 경로 중 한 칸이라도
공원 밖이거나 장애물이면 그 명령 전체를 무시하고, 아니면 끝점으로 이동한다.
모든 명령 뒤 위치를 `[행, 열]`로 반환하라.

## 함수 인터페이스

```python
def solution(park, routes):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- 공원의 행과 열 길이는 각각 3 이상 50 이하이다.
- 시작점 `S`는 정확히 하나이다.
- `routes`의 길이는 1 이상 50 이하이다.
- 방향은 `N`, `S`, `W`, `E` 중 하나이고 거리는 1 이상 9 이하이다.
- 좌측 상단 좌표는 `[0, 0]`이다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `park = ['SOO', 'OOO', 'OOO']; routes = ['E 2', 'S 2', 'W 1']` | `[2, 1]` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `park = ['SOO', 'OXX', 'OOO']; routes = ['E 2', 'S 2', 'W 1']` | `[0, 1]` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `park = ['OSO', 'OOO', 'OXO', 'OOO']; routes = ['E 2', 'S 3', 'W 1']` | `[0, 0]` |

## 예제 해설

> **핵심:** 각 명령의 모든 중간 칸이 경계 안이고 장애물이 없을 때만 이동한다. 첫 예제의 유효한 이동을 적용한 마지막 좌표는 `[2, 1]`이다.

# DFS/BFS 마스터 가이드

## 이 유형의 본질

DFS와 BFS는 배열이나 문자열로 보이는 문제를 **정점과 간선으로 바꿔 도달 가능한
상태를 체계적으로 방문하는 방법**이다.

- DFS: 한 경로를 끝까지 따라가며 모든 가능성, 연결 요소, 백트래킹을 탐색
- BFS: 시작점에서 거리 층을 넓혀 가며 가중치가 같은 간선의 최단거리 탐색

마스터는 DFS/BFS 코드를 외우는 사람이 아니라 정점, 간선, 방문 상태, 종료 조건을
정확히 모델링하는 사람이다.

## 문제에서 포착할 신호

- 연결되어 있는 그룹 수, 도달 가능성, 경로 존재 여부
- 격자에서 상하좌우/대각선 이동
- 연산을 몇 번 적용해 목표 상태에 도달
- 모든 경로/순서를 탐색하거나 최단 단계 수를 구함
- 한 상태에서 다음 상태 목록을 자연스럽게 생성 가능
- 네트워크, 전력망, 단어 변환, 퍼즐 조각 같은 관계 서술

## 핵심 사고

문제의 명사를 정점으로, 한 번의 합법적인 변화를 간선으로 바꾼다. 그다음 필요한
것이 모든 도달 상태인지, 연결 요소인지, 최소 단계인지 결정한다. 탐색 코드는 마지막
단계이며, 같은 위치라도 미래 행동이 달라지는 추가 상태를 `visited` 키에 포함하는
모델링이 가장 중요하다.

## 모델링 4문장

코드 전에 반드시 채운다.

```text
정점:
간선:
visited/dist가 의미하는 것:
탐색 종료 및 반환값:
```

예: 단어 변환에서 정점은 단어, 간선은 한 글자만 다른 두 단어, 거리는 변환 횟수다.

## DFS와 BFS 선택

| 목적 | 우선 선택 |
|---|---|
| 무가중치 최단거리 | BFS |
| 연결 요소 개수 | 둘 다 가능 |
| 모든 선택 경로·백트래킹 | DFS |
| 트리의 깊은 재귀 구조 | DFS |
| 시작점 여러 개의 동시 확산 | 다중 시작점 BFS |
| 간선 가중치가 다름 | BFS가 아니라 Dijkstra 등 검토 |

## 핵심 불변식

- BFS 큐: 큐에서 꺼낼 정점의 거리는 비감소 순서다.
- 첫 방문: 무가중치 그래프에서 처음 방문했을 때 최단거리가 확정된다.
- DFS 방문: 현재 호출 경로 또는 전체 탐색에서 방문한 정점을 명확히 구분한다.
- 백트래킹: 경로 방문 표시를 복구해야 하는지, 전역 방문으로 유지할지 목적에 따라 결정한다.

## 구현 패턴

### 격자 BFS

```python
from collections import deque

queue = deque([(start_r, start_c)])
distance = [[-1] * width for _ in range(height)]
distance[start_r][start_c] = 0

while queue:
    r, c = queue.popleft()
    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        nr, nc = r + dr, c + dc
        if not (0 <= nr < height and 0 <= nc < width):
            continue
        if blocked(nr, nc) or distance[nr][nc] != -1:
            continue
        distance[nr][nc] = distance[r][c] + 1
        queue.append((nr, nc))
```

방문 표시는 enqueue할 때 한다. dequeue할 때 표시하면 같은 정점이 큐에 여러 번 들어간다.

### 반복형 DFS

```python
stack = [start]
visited = {start}
while stack:
    node = stack.pop()
    for neighbor in graph[node]:
        if neighbor not in visited:
            visited.add(neighbor)
            stack.append(neighbor)
```

### 선택 DFS

```python
def dfs(index, state):
    if index == len(items):
        evaluate(state)
        return
    dfs(index + 1, choose_plus(state, items[index]))
    dfs(index + 1, choose_minus(state, items[index]))
```

## 방문 상태 설계

같은 위치라도 열쇠 보유, 방향, 남은 횟수, 사용한 티켓이 다르면 서로 다른 정점일 수
있다. 반대로 과거 경로 전체가 미래에 영향을 주지 않으면 방문 상태에서 제거해야 한다.
상태가 `(r, c, extra)`라면 최대 상태 수를 곱해 복잡도를 계산한다.

## 자주 틀리는 이유

- BFS 방문 표시를 늦게 해 큐가 폭증한다.
- 시작 칸 거리 포함 여부가 한 칸 어긋난다.
- 행/열과 x/y를 뒤바꾼다.
- 재귀 DFS에서 전역 방문과 경로 방문을 혼동한다.
- 단어/퍼즐을 그래프로 만들 때 간선 조건이 한 글자/상하좌우인지 틀린다.
- 최단거리인데 DFS로 모든 경로를 탐색해 시간 초과가 난다.
- 사용한 티켓을 값 집합으로 관리해 중복 티켓을 잃는다.

## 디버깅 방법

- 큐에서 꺼낸 `(상태, 거리)`를 처음 20개만 출력해 거리 층이 비감소인지 본다.
- 모든 간선을 작은 그림에 그리고 실제 코드가 만든 인접 목록과 비교한다.
- 연결 요소는 방문 직후 번호를 칠해 시각화한다.
- 상태가 복합이면 `visited` 키를 출력해 서로 달라야 할 상태가 합쳐지지 않았는지 확인한다.

## 효율적인 훈련법

- 같은 연결 요소 문제를 재귀 DFS, 반복 DFS, BFS 세 방식으로 푼다.
- 작은 그래프를 무작위 생성해 Floyd-Warshall 거리와 BFS 거리를 비교한다.
- 격자 문제는 방향 배열, 범위 검사, 방문 표시 코드를 빈 파일에서 5분 내 작성한다.
- 문제 서술을 읽고 코드 없이 정점/간선/상태 수만 정의하는 훈련을 10문제 한다.

## 문제

`players`는 현재 1등부터의 선수 이름이고 `callings`는 경기 중
해설자가 차례로 부른 이름이다. 이름이 불린 선수는 그 순간 바로 앞 선수를
추월하여 두 사람의 순위가 바뀐다. 모든 호출을 처리한 최종 순위를 반환하라.

## 함수 인터페이스

```python
def solution(players, callings):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `players`의 길이는 5 이상 50,000 이하이다.
- 선수 이름은 서로 다르며 길이 3~10의 알파벳 소문자 문자열이다.
- `callings`의 길이는 2 이상 1,000,000 이하이다.
- 호출되는 이름은 항상 `players`에 있으며, 호출 순간의 1등은 불리지 않는다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

**INPUT**

```python
players = ['mumu', 'soe', 'poe', 'kai', 'mine']
callings = ['kai', 'kai', 'mine', 'mine']
```

**OUTPUT**

```python
['mumu', 'kai', 'mine', 'soe', 'poe']
```

## 예제 해설

> **핵심:** 호출된 선수가 바로 앞 선수를 추월할 때마다 두 선수의 위치를 함께 바꾸면 마지막 순위가 `[mumu, kai, mine, soe, poe]`가 된다.

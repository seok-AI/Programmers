> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 난이도 | Level 2 |
| 학습 유형 | 해시 |
| 호출 함수 | `solution(phone_book)` |
| 매개변수 | `phone_book` |
| 반환형 | `bool` |

## 문제

중복되지 않는 전화번호 목록 `phone_book`이 주어진다. 목록의 서로
다른 두 번호 중 하나가 다른 하나의 맨 앞부분과 완전히 일치하는 경우가 하나라도
있으면 `False`, 그런 쌍이 전혀 없으면 `True`를 반환하라.

## 함수 인터페이스

```python
def solution(phone_book):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `phone_book`의 길이는 1 이상 1,000,000 이하이다.
- 전화번호 하나의 길이는 1 이상 20 이하이다.
- 전화번호는 숫자로 이루어진 문자열이다.
- 동일한 전화번호는 두 번 주어지지 않는다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `phone_book = ['119', '97674223', '1195524421']` | `False` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `phone_book = ['123', '456', '789']` | `True` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `phone_book = ['12', '123', '1235', '567', '88']` | `False` |

## 예제 해설

> **핵심:** 첫 예제에서 `119`가 `1195524421`의 앞부분과 같으므로 접두어 관계가 존재해 `false`이다.

## 문제

종류 번호가 기록된 `nums`에는 N마리의 생물이 있다. 이 중 정확히
N/2마리를 고를 때 포함할 수 있는 서로 다른 종류 수의 최댓값을 반환하라.
같은 번호는 같은 종류를 뜻한다.

## 함수 인터페이스

```python
def solution(nums):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `nums`의 길이 N은 1 이상 10,000 이하인 짝수이다.
- 각 종류 번호는 1 이상 200,000 이하이다.
- 선택 방법이 여러 개여도 가능한 종류 수의 최댓값만 반환한다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `nums = [3, 1, 2, 3]` | `2` |

### 예제 2

| INPUT | OUTPUT |
|---|---|
| `nums = [3, 3, 3, 2, 2, 4]` | `3` |

### 예제 3

| INPUT | OUTPUT |
|---|---|
| `nums = [3, 3, 3, 2, 2, 2]` | `2` |

## 예제 해설

> **핵심:** 첫 예제는 두 마리를 고를 수 있고 종류가 세 가지이므로, 서로 다른 두 종류를 골라 최댓값 2를 만든다.

# 그래프 마스터 가이드

## 이 유형의 본질

그래프는 “노드와 간선이 주어졌다”는 문제만 뜻하지 않는다. 사람 사이 승패, 공항과
항공권, 상태 전환, 키패드 이동, 네트워크 장비 연결처럼 **대상 사이 관계가 핵심인
모든 문제를 표현하는 언어**다.

이 폴더의 DFS/BFS를 넘어 마스터해야 할 축은 다음과 같다.

- 도달성과 연결 요소
- 최단경로: BFS, Dijkstra, Floyd-Warshall
- 최소 연결: MST(Kruskal/Prim)
- 선후관계: 위상정렬
- 모든 쌍 관계와 전이 폐쇄
- 사이클·Union-Find·Euler 경로

## 문제에서 포착할 신호

- 대상과 관계가 쌍으로 주어진다.
- 직접 관계로 간접 관계를 추론해야 한다.
- 모든 정점을 연결하거나 순위를 확정한다.
- 출발점에서 가장 멀거나 가장 가까운 정점을 찾는다.
- 새 간선이 닫힌 영역/사이클을 만드는지 센다.
- 현실 서술을 정점과 간선으로 바꾸면 규칙이 단순해진다.

## 그래프 모델링 질문

1. 정점 하나는 무엇인가? 위치인가, 사람인가, 전체 상태인가?
2. 간선은 방향이 있는가?
3. 가중치가 있는가? 음수가 가능한가?
4. 같은 두 정점 사이 중복 간선이 가능한가?
5. 그래프가 연결, 트리, DAG라는 보장이 있는가?
6. 필요한 답이 경로, 거리, 연결성, 순서, 사이클 중 무엇인가?

이 여섯 답이 알고리즘을 거의 결정한다.

## 알고리즘 선택 지도

| 조건과 목적 | 알고리즘 |
|---|---|
| 무가중치 한 시작점 최단거리 | BFS |
| 음수 없는 가중치 한 시작점 | Dijkstra |
| 모든 쌍, n이 작음 | Floyd-Warshall |
| 모든 정점 최소 비용 연결 | Kruskal/Prim |
| 동적 연결 여부·사이클 | Union-Find |
| DAG 선후관계 | 위상정렬 |
| 모든 간선을 정확히 한 번 | Euler 경로 검토 |
| 트리 경로/서브트리 | DFS, LCA, 트리 DP |

## 표현 방식

### 인접 리스트

희소 그래프에서 기본이다. 공간 `O(V+E)`.

```python
graph = [[] for _ in range(n + 1)]
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)
```

### 인접 행렬

n이 작고 모든 쌍 관계가 필요할 때 쓴다. 공간 `O(V^2)`.

```python
reachable = [[False] * n for _ in range(n)]
```

### Union-Find

```python
parent = list(range(n))
rank = [0] * n

def find(x):
    while x != parent[x]:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb:
        return False
    if rank[ra] < rank[rb]:
        ra, rb = rb, ra
    parent[rb] = ra
    if rank[ra] == rank[rb]:
        rank[ra] += 1
    return True
```

## 핵심 알고리즘 사고

### 최단거리

경로 자체보다 “어떤 정점의 최단거리가 언제 확정되는가?”를 이해한다. BFS는 같은
가중치, Dijkstra는 음수 없는 가중치라는 조건이 필요하다.

### 전이 폐쇄

A가 B를 이기고 B가 C를 이기면 A가 C를 이긴다는 관계는 모든 쌍 도달성이다. n이
100 정도면 Floyd-Warshall의 `O(n^3)`이 단순하고 안전하다.

```python
for k in range(n):
    for i in range(n):
        if not reachable[i][k]:
            continue
        for j in range(n):
            reachable[i][j] |= reachable[k][j]
```

### 사이클과 방

무방향 그래프에 아직 연결되지 않은 두 정점을 잇는 간선은 연결 요소를 합치고, 이미
연결된 두 정점을 새 간선으로 이으면 사이클 수가 늘 수 있다. 선분 중간 교차처럼 새
정점이 생기는 문제는 좌표를 확대해 교차를 정점으로 표현한다.

## 자주 틀리는 이유

- 방향/무방향 간선을 반대로 넣는다.
- 정점 번호가 1부터인데 배열을 n칸만 만든다.
- 중복 간선과 자기 루프를 고려하지 않는다.
- Dijkstra에 음수 간선을 사용한다.
- 최단거리와 단순 방문 여부를 같은 배열 값으로 혼동한다.
- 간접 승패를 한 단계만 전파하고 전체 전이 폐쇄를 하지 않는다.
- 대각선 교차점을 정점으로 만들지 않아 사이클을 놓친다.

## 복잡도 감각

- BFS/DFS: `O(V+E)`
- Dijkstra(힙): `O((V+E) log V)`
- Floyd-Warshall: `O(V^3)`, 공간 `O(V^2)`
- Kruskal: 간선 정렬 때문에 `O(E log E)`
- Union-Find 연산: 경로 압축과 랭크 사용 시 거의 상수에 가까운 상각 시간

n과 E를 보고 행렬/리스트를 선택한다. n=20,000에 인접 행렬을 만들면 메모리부터
실패한다.

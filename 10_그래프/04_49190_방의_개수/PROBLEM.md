> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

## 문제

좌표 `(0,0)`에서 시작해 `arrows`를 순서대로 따라 선분을
그린다. 방향 번호는 시계 방향으로 `0=위, 1=오른쪽 위, 2=오른쪽,
3=오른쪽 아래, 4=아래, 5=왼쪽 아래, 6=왼쪽, 7=왼쪽 위`이다.
새 선분으로 평면에 새로 생기는 닫힌 방의 총개수를 반환하라. 선분 중간에서
대각선끼리 교차하여 생기는 정점도 고려해야 한다.

## 함수 인터페이스

```python
def solution(arrows):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `arrows`의 길이는 1 이상 100,000 이하이다.
- 각 원소는 0 이상 7 이하이다.
- 이미 지나간 정점이나 간선을 다시 지날 수 있다.
- 방 안에 또 다른 방이 생길 수 있다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `arrows = [6, 6, 6, 4, 4, 4, 2, 2, 2, 0, 0, 0, 1, 6, 5, 5, 3, 6, 0]` | `3` |

## 예제 해설

> **핵심:** 대각선 교차를 놓치지 않도록 각 이동을 둘로 나눈 뒤, 이미 본 정점에 새 간선으로 들어가는 횟수를 세면 방이 세 개다.

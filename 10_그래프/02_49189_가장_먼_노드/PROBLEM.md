> 이 문서는 공식 지문을 복제하지 않고, 인터넷 없이 풀이할 수 있도록 문제의
> 동작 규칙과 제한을 독립적으로 재서술한 명세입니다.

| 항목 | 내용 |

| 학습 유형 | 그래프 |
| 호출 함수 | `solution(n, edge)` |
| 매개변수 | `n`, `edge` |
| 반환형 | `int` |

## 문제

1번부터 n번까지의 정점과 무방향 간선 `edge`가 주어진다.
1번 정점에서 각 정점까지의 최단 간선 수를 구했을 때 그 값이 가장 큰 정점의
개수를 반환하라.

## 함수 인터페이스

```python
def solution(n, edge):
    ...
```

매개변수는 위 순서로 전달하며, 반환값은 문제에서 요구한 Python 값이어야 한다.
표준 입력을 읽거나 표준 출력에 답을 쓰는 문제가 아니다.

## 규칙과 제한사항

- `n`은 2 이상 20,000 이하이다.
- 간선 수는 1 이상 50,000 이하이다.
- 각 간선 `[a, b]`는 a와 b를 양방향으로 연결한다.
- 1번에서 계산 대상 정점으로 도달 가능한 입력이 주어진다.

## 공개 예제

> `INPUT`은 `solution()`에 전달되는 매개변수이며, `OUTPUT`은 함수가 반환해야 할
> 값입니다. 짧은 값은 좌우 표로, 긴 격자·중첩 배열은 코드 블록으로 표시합니다.

### 예제 1

| INPUT | OUTPUT |
|---|---|
| `n = 6; edge = [[3, 6], [4, 3], [3, 2], [1, 3], [1, 2], [2, 4], [5, 2]]` | `3` |

## 예제 해설

> **핵심:** 1번에서 BFS 거리를 계산하면 가장 큰 거리에 있는 노드가 세 개이므로 3을 반환한다.
